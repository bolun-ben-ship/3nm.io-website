The sequence

Six steps. Same order, every time.

Every engagement runs the same path. Discovery call free; the workflow audit is paid. After commit, you see the plan before any build, and you can stop anytime with no penalty.

01

Discovery call.

30 minutes. Your business, your bottleneck, whether what I build is the right answer. No pitch. If it's not a fit, you hear it on the call.

30 MIN · FREE
02

Workflow audit.

About an hour, together. Tools, data, manual processes. The audit identifies which workflow becomes the automation, which data feeds the dashboard, where the friction lives. Commit here and scope begins.

1 HOUR · FREE
03

Written scope.

Deliverables, scope, assumptions; every Function and Enhancement bundled. No vague statements of work. We meet to agree. You see the plan before any build.

BEFORE ANY BUILD
04

Working MVP.

Operational dashboard live on real data: revenue, pipeline, team capacity, client health. Not a mockup. Not a demo. Two iteration rounds, in your environment, behind authentication. Stop anytime — no penalty.

ON REAL DATA
05

Foundation Build.

Four functions complete: operational dashboard, workflow automation, AI assistant, notification centre. Plus hosting, authentication, database, agreed data connections. I build until it's live and doing the job. Written into the agreement.

SCOPED TO YOU
06

Handover, then either path.

Code, infrastructure, SOPs, knowledge wiki: every artefact yours. No licenses retained. From here, two paths, switch any time. Function Cycles add capability on the same cadence, scoped per cycle. Maintain Mode keeps it supported: hosting, updates, AI refresh, async.

YOURS · FOREVER
What you receive

Four functions. One operating system.

Same four functions every Foundation Build. Built around your data and workflows. Same architecture, same commitments.

Function 01
Operational dashboard

Revenue, pipeline, team capacity, client health. One view. Role-based from day one. First to go live as MVP on real data.

Function 02
Workflow automation

One workflow chosen in scoping. Compliance chains, data-to-PDF, intake forms, review pipelines. The hour-eater, gone.

Function 03
AI assistant

Plain English. "Who's overdue?" "Pipeline this month?" Answers from your live data, in seconds, with citations to the records.

Function 04
Notification centre

Thresholds you set. Revenue dips, client risk, capacity flags, deadlines. No noise. Only signals you asked for.

Plus, included

Hosting, authentication, database. 2 to 3 data connections from scoping (finance, calendar, email, one business-specific). Knowledge wiki initialised: SOPs, roles, decisions, rules; cross-linked, searchable from the AI assistant.

The agreement

What we each commit to.

These aren't aspirations. Every commitment below is in the service agreement, spelled out in writing.

Stop anytime
No lock-in. No minimums.

Stop anytime — no penalty. Work delivered is yours. The guarantee is performance: I build until it's live and doing the job.

Scope freeze
Once approved, the scope holds.

Enhancements bundled before build. New requests after approval go to the next Function Cycle. Every request classified before it changes scope.

Speed is mutual
Fast feedback. Both sides.

I move fast on scope and MVP. You give fast feedback. If feedback runs longer, the schedule adjusts, in writing, flagged up front.

Total ownership
Code, database, SOPs, wiki.

Source, infrastructure, deployment, knowledge wiki. All transferred on delivery. No licenses retained. If we part ways, the system keeps working.
