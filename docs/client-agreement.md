## 1. Services

RightClick:AI builds custom AI operating systems for service businesses. This agreement covers three service types:

- **Foundation Build** — the initial four-function system
- **Function Cycles** — individual capability additions after the Foundation
- **Maintain Mode** — ongoing hosting, maintenance, and support

All work is delivered by Ben directly. No subcontractors, no handoffs.

---

## 2. Foundation Build

**Price:** SGD 6,800 (fixed)

### What's included

**Four functions:**
1. Operational dashboard with role-based access
2. Revenue and pipeline tracker
3. AI assistant (natural language queries over connected data)
4. Notification and alert centre

**Infrastructure (built once, included in Foundation price):**
- Hosting, authentication, and database architecture
- 2–3 initial data connections (Xero required if available, plus one additional source agreed in the scoping document)
- Lightweight project and capacity status views
- User and role management

### Timeline commitments
- Scope document: within 48 hours of engagement start
- Working MVP: within 7 days of scope document approval
- Full build: within 6–8 weeks of scope document approval

### What is not in the Foundation Build
The following require separate function cycles and are not included in the Foundation price:
- WhatsApp integration
- External client-facing portals
- Complex reporting or analytics beyond standard dashboard views
- Workflow automation beyond basic notification triggers
- Any data source connection beyond the initial 2–3 agreed in the scoping document

## 3. Function Cycles

**Price:** SGD 2,400 per function cycle

**Pre-purchase option:** 3 function cycles for SGD 6,600 (SGD 2,200 each). Unused credits are fully refundable.

### Each cycle delivers
- Scope document within 48 hours of cycle start
- Working MVP within 7 days of scope document approval
- Full build within 4 weeks of scope document approval

### What counts as a Function
A function requires at least one of the following:
- Connecting to a new data source or external system not previously integrated
- Automating a workflow that currently requires a human decision or manual step
- Surfacing information that currently requires someone to compile or retrieve manually
- Building a new interface or module that did not previously exist in the system
- Creating a new AI workflow, agent, or automation with custom logic

---

## 4. Enhancements

Enhancements are minor additions to existing functions. They do not require a separate function cycle and do not have their own SLA timeline.

### The complete list of enhancements (exhaustive — anything not listed here is a Function)
- Search and filtering on an existing view
- Export to CSV or PDF of existing data
- Notes, comments, or tags on any record
- Notifications and alerts triggered by logic already built into the system
- Sorting, pagination, and date range filters on existing views
- Adding new columns or fields to an existing table
- Adjusting user permissions within an existing role structure
- UI, layout, or visual changes to existing views
- Adding a new user or modifying access for an existing user

### Enhancement billing
- During an active function cycle: included at no charge
- During Maintain Mode: 2 enhancement requests per quarter at no charge; SGD 300 per request thereafter

### Classification commitment
Builder will classify any request as Function or Enhancement within 24 hours of receipt.

## 7. Scope Management

### Scope freeze
Once Client approves the scope document, the scope for that cycle is locked. New requests received after approval are logged and addressed as follows:
- Classified as a Function → queued for next function cycle
- Classified as an Enhancement → queued for current or next Maintain Mode period

Builder is not obligated to include new requests in the current build cycle.

**Exception:** At Builder's sole discretion, if a request can be completed in under 2 hours and poses no risk to current SLA deadlines, Builder may include it. This is not a client right and does not create an obligation.

### Enhancement requests during active build
Enhancement requests made during an active build cycle are logged but not added to the current scope. No SLA timeline applies to logged enhancements — they are addressed in order once the current cycle is complete or in Maintain Mode.
